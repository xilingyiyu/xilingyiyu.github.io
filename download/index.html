📝 安装步骤

  1. 下载并解压

    下载 ZIP 压缩包，解压到任意目录（如 C:\SSHFS_Tool）

  2. 运行安装程序

    右键点击 install.bat，选择"以管理员身份运行"

    install.bat

  3. 配置连接信息

    双击桌面上的"SSHFS 配置工具"，填写服务器信息：

    主机地址: wheshell.hpccube.com
    端口号: 65032
    用户名: scnjvcq935
    远程路径: /
    本地盘符: Z:
    私钥文件: [选择你的 .ppk 文件]

  4. 测试连接

    点击"测试连接"按钮，验证 SSH 连接是否正常

  5. 启用自动挂载

    勾选"开机自动挂载"，保存配置，重启电脑即可自动挂载

📖 使用说明

💡 提示：首次使用需要准备 SSH 密钥对。可以使用 PuTTYgen 生成密钥， 将公钥上传到服务器的 ~/.ssh/authorized_keys，私钥保存为 .ppk 格式。

生成密钥对

  1. 下载 PuTTYgen

    访问 https://www.puttygen.com/ 下载 PuTTYgen

  2. 生成密钥

    打开 PuTTYgen，选择 SSH-2 RSA，点击 Generate，移动鼠标生成密钥

  3. 保存私钥

    点击 Save private key，保存为 private_key.ppk

  4. 上传公钥

    复制 Public key 内容，上传到服务器的 ~/.ssh/authorized_keys

手动挂载

如果不想使用自动挂载，可以手动运行：

mount_auto.bat

卸载

在安装目录中找到 uninstall.bat，右键以管理员身份运行

❓ 常见问题

Q: 挂载失败怎么办？
A: 请检查：
1. SSH 服务是否在服务器上运行
2. 端口 65032 是否已开放
3. 用户名和密钥是否正确
4. 私钥文件是否为 .ppk 格式
Q: 如何更改盘符？
A: 在配置界面中选择其他盘符（如 Y:, X:），保存配置即可。
Q: 如何禁用开机自启动？
A: 运行配置工具，取消勾选"开机自动挂载"，保存配置即可。
Q: 支持密码认证吗？
A: 当前版本仅支持密钥认证。如需密码认证，请修改 mount_auto.bat 脚本。
